AsiaPride

This website serves as a landing page for a Growtopia Private Server called "Asia The Uprising." The main section features a bold title with a glowing effect, accompanied by a short description highlighting exclusive gameplay features such as ghost catching, fishing, surgery, and Carnival events. Two prominent call-to-action buttons, Play Now and Check Feature, guide users to start playing or explore more details. The design uses a dark gradient background with neon blue accents, creating a modern and immersive gaming atmosphere, while a simple top navigation menu ensures easy access to Home, Feature, and Play sections.

You can view the website here: https://asiapride100-lgtm.github.io/asiapride/
